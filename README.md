# Wanderflow – A Comprehensive Travel Booking and Exploration Platform

An academic frontend travel exploration website developed by B.Tech Information Technology students during their four-week training at **Guru Nanak Dev Engineering College (GNDEC), Ludhiana** (June – July 2026).

---

## 📌 Project Overview

**Wanderflow** is designed to streamline the travel discovery and trip planning process. It provides a clean, unified platform where users can explore popular domestic and international destinations, review seasonal guidelines and attractions, compare holiday tour packages, and submit booking inquiries.

Built strictly using **pure HTML5 and modern CSS3** in accordance with the training syllabus, the platform features clean semantic markup, accessible layouts, responsive card designs, and zero external framework dependencies.

---

## 🌐 Website Pages (Interconnected)

1. **Home (`index.html`):**
   - Sticky navigation header with brand logo.
   - Hero banner with travel imagery, tagline, and call-to-action buttons.
   - Frontend travel search filter form (Destination, Date, Travellers, Category).
   - Popular destination cards (Manali, Goa, Kashmir, Jaipur, Bali, Switzerland).
   - "Why Choose Wanderflow" feature highlights.
   - Comprehensive footer with quick links and academic attribution.

2. **Destinations (`destinations.html`):**
   - Detailed destination guides covering 6 top global and domestic locations.
   - High-resolution photography and geographic coordinates.
   - Popular tourist attractions (unordered lists `<ul>`).
   - Best time to visit highlights.
   - Top recommended travel activities (ordered lists `<ol>`).
   - Direct package integration links.

3. **Travel Packages (`packages.html`):**
   - 5 curated holiday packages with duration badges, price highlights (`<mark>`), and inclusions.
   - Side-by-side **Package Comparison Matrix Table** (`<table>`, `<caption>`, `<thead>`, `<tbody>`, `<tfoot>`).
   - Frontend **Package Booking Inquiry Form** with input validations and an academic disclaimer.

4. **About Us (`about.html`):**
   - Project purpose and synopsis problem statement.
   - Core project objectives and training scope.
   - Technical limitations (frontend demonstration, no backend/database).
   - Technology stack breakdown table.
   - Student development team profiles and institutional attribution (GNDEC IT).

---

## 🛠️ Technologies Used

- **HTML5:** Semantic elements (`header`, `nav`, `main`, `section`, `article`, `footer`), headings (`h1`–`h4`), formatting tags (`strong`, `em`, `mark`, `small`), hyperlinks, images, lists, tables, and form controls.
- **CSS3:** Custom stylesheet (`style.css`), color palette (Navy Blue, Sky Blue, White, Beige, Light Grey), Flexbox, CSS Grid, smooth transitions, box-shadows, and responsive media queries (`@media (max-width: 768px)`).
- **No JavaScript / No Frameworks:** 100% vanilla, beginner-friendly frontend code.
